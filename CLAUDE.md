# Planner A1

Личный планировщик и трекер целей для телефона, планшета и компьютера. Один файл `index.html` (HTML + CSS + JS без сборки и зависимостей). Владелец проекта не программист, поэтому объясняйте простым языком и показывайте результат, а не код. Язык общения: русский.

Идея на будущее: встроенный ИИ-агент, который подсказывает по эффективности и дисциплине, настоящие аккаунты и вход, интеграции (Worksection, Garmin).

## Как сейчас публикуется
- Приложение публикуется как приватный Artifact на claude.ai (ссылка: https://claude.ai/artifact/NZ6unpRNK9eqYYFyk6d8mR), версия на момент переноса: 66, после защиты синхронизации: 67.
- Возможности Artifact: `db` и `user` (облачная синхронизация между устройствами) и `mcp` (Google Calendar: list_calendars, list_events, create_event, update_event, delete_event).
- Источник правды теперь этот репозиторий (`index.html`). После правок файл публикуется в тот же Artifact.
- Тесты: Playwright (Chromium) с подменой `window.claude` (`claude.use('db'|'user'|'mcp')`) и `SpeechRecognition`; перед публикацией скрипт вынимается из `<script>` и проверяется `node --check`.

## Вкладки
Ежедневник (день / неделя / месяц), Мешок задач (шарики-физика на canvas), Цели по сферам, Результаты, Настройки. Вкладка «Стратегия» (инструменты «Слон» и «Штурвал») скрыта (`hidden` у кнопки `data-tab="strat"`), код сохранён, её нужно доработать позже.

## Данные
Состояние `S` хранится в localStorage (`planner-v1`) через `save()`:
`spheres, goals, tasks, done['id|YYYY-MM-DD'], zones, bag, notes[day], wake, bed, life, theme, lang, sync, gcal`.
- `tasks`: `{id,title,sphere,start,dur,date,repeat,days,until,goal,fromBag,gsrc}`.
- `bag` (шарики): `{id,title,sphere,imp,tid,goal,focus,due,cr,gsrc}`. `due` и `cr` задают кольцо-таймер (от момента создания/начала до конца дня срока).
- `notes[day]`: `{h (html), d (png dataURL рисунка), lh (логическая высота поля), im (картинки)}`.

## Основные модули в index.html
- i18n (ru/en/pl/uk): словарь `DICT` + `RX`, функция `tr()`, MutationObserver; каждая новая строка интерфейса требует записи в `DICT`.
- Облачная синхронизация (`db`): куски `main` и `n-<день>`, хеш `hsh`, разрешение конфликтов «последний победил» по `S.sync.mt`, локальная копия перезаписанного куска в `planner-backup-<key>`.
- Резервные копии: до 12 снимков в localStorage (`planner-snap-<ts>`), восстановление в Настройках.
- Google Календарь (`gcSync`): двусторонне для задач приложения (связки `S.gcal.map`), события Google с временем приходят как задачи (`imp`), многодневные события приходят шариками в мешок с таймером, остальные показываются серым. Свои события узнаются по описанию «Создано в приложении «Planner A1»» (раньше «Розвиватор A1»). Есть защита от дублей, лимит 30 операций за запуск, пауза 45 минут при ошибке квоты Google. Приложение никогда не удаляет задачи из-за пропажи события с первого раза.
- Заметки со стилусом: canvas поверх contenteditable, режим «Только стилус» (палец только прокручивает), защита от касаний ладони, клетка на фоне, кнопка «Растянуть поле», асинхронное сохранение.
- Голосовые задачи: кнопка микрофона (Web Speech API), разбор даты, времени и длительности для ru/uk/pl/en.
- Колёса выбора времени и длительности, цитата дня (200 цитат), эффективность дня (кольца).

## Защита синхронизации (v67)
- Пустой/кэшированный первый ответ облака не считается готовой синхронизацией; пустое `main` без известного прошлого не отправляется.
- Отправка `main` блокируется, если задач+шариков+целей стало меньше 40% от известного в облаке (баннер «Отправить всё равно» / «Восстановить из облака»), перед этим делается снимок.
- Пустое `main` из облака не применяется, если локально данные есть: облако восстанавливается из локальных данных.
- В `p/main` хранится счётчик `c`; облачная копия последнего здорового состояния — `c/bak~i` и `c/bakm` (не чаще раза в 30 мин), кнопка в Настройках → «Резервные копии».

## Принципы
- Не терять данные пользователя: любые автоматические удаления только после повторной проверки, перед рискованными операциями делать снимок (`snapTake(true)`).
- Не вставлять секреты (ключи, client secret) в этот файл: страница публична для всех, у кого есть код.
- Сначала понятный результат для пользователя, потом детали.
