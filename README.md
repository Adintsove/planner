# ADN Planner

Личный планировщик: ежедневник, мешок задач с таймерами, цели по сферам, заметки со стилусом, синхронизация с Google Календарём.

Весь код в одном файле `index.html`. Описание устройства и планов: [CLAUDE.md](CLAUDE.md).


Открыть как приложение: https://adintsove.github.io/planner/ (вход через Google, установка на главный экран).
